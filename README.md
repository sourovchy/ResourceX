# ResourceX

**ResourceX** is a Cross-Campus Resource Sharing Platform focused on making campus resource sharing simpler, safer, and more accessible for university students.

The platform enables students to rent, borrow, and manage academic or personal resources through a secure and organized system, helping reduce unnecessary expenses while promoting efficient resource utilization across campuses.

This project is being developed as a **Level 2 Term 2 CSE 252: Database Management Systems (Sessional)** and **CSE 202: Software Development with JAVA (Sessional)** project under the Department of CSE, CUET.

---

## Key Features

- Secure student-only access
- Cross-campus borrowing and lending
- Smart booking and rental management
- Organized listings with search and filtering
- Reviews, ratings, and trust-based interactions
- Payment tracking and centralized moderation
